# Watchlist для news/ (GDELT) — активи поза акціями S&P 500

Цей документ визначає, за якими активами відстежуємо новини — окремо
від скринінгу акцій S&P 500 (`docs/screening-criteria.md`). Джерело
даних для новин (`news/`, GDELT) ще не побудовано — це визначення
**що** відстежувати, а не **як**; вибір джерел котирувань для цих
класів активів (крипто/форекс/commodities) — окреме, ще не прийняте
рішення.

## Watchlist (закрито, 2026-09-25)

| Клас | Актив |
|---|---|
| Метали | Золото (XAU/USD), Срібло (XAG/USD) |
| Енергоносії | Нафта — WTI і Brent (обидва бенчмарки) |
| Softs | Кава |
| Валютні пари | EUR/USD, USD/JPY |
| Крипто | BTC, ETH, SOL |

**Рішення (крипто):** BTC + ETH + SOL — підтверджено користувачем
2026-09-25 (розширено проти початкового припущення BTC+ETH; SOL додано
як третя за капіталізацією монета великої окремої екосистеми поза
Ethereum).

**Рішення (нафта):** обидва бенчмарки — WTI і Brent, не один на вибір.
Підтверджено користувачем 2026-09-25.

**Рішення (пріоритет 2 "загальні активи"):** прибрано. Користувач
підтвердив 2026-09-25, що список вище — повний, розширення індексами/
ETF/додатковими валютними парами/металами не потрібне.

## Категорія в схемі

`db/schema.sql` вже передбачає окремі категорії джерел під це —
`crypto`, `forex`, `commodities`, `news` (коментар над `category` в
`sources`) — жодної зміни схеми не потрібно, коли дійдемо до коду.

## Зв'язок зі скринінгом акцій

Окремо від цього списку: `docs/screening-criteria.md` уже має
механізм "акція з новин → перевірка Tier B → в список" для S&P 500.
Цей watchlist — про інший клас активів (не акції), тому окремий
документ, а не розширення screening-criteria.md.
