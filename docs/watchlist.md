# Watchlist для news/ (GDELT) — активи поза акціями S&P 500

Цей документ визначає, за якими активами відстежуємо новини — окремо
від скринінгу акцій S&P 500 (`docs/screening-criteria.md`). Джерела
котирувань для цього списку вже вибрані й побудовані (нижче); розширення
переліку понад цей закритий список — на розсуд користувача, через файл
вибраних активів, не через нові адаптери (докладніше нижче).

підтвердив 2026-09-25, що список вище — повний, розширення індексами/
ETF/додатковими валютними парами/металами не потрібне.

## Категорія в схемі

`db/schema.sql` вже передбачає окремі категорії джерел під це —
`crypto`, `forex`, `commodities`, `news` (коментар над `category` в
`sources`) — жодної зміни схеми не потрібно, коли дійдемо до коду.

**Крипто (BTC/ETH/SOL) — адаптери написані 2026-09-26, живо
підтверджено:** `data-ingestion/crypto/binance_adapter.py` (ціна/обсяг,
першоджерело біржі) + `data-ingestion/crypto/coingecko_adapter.py`
(market cap, агрегатор) — деталі й обґрунтування вибору ролей —
`docs/decisions.md`.

**Усі 6 watchlist-активів поза акціями тепер мають ціну (2026-09-26):**
метали/енергоносії/softs/валютні пари — через FRED/Twelve Data
(`docs/news-purpose.md`, Ціль 1); срібло (XAG/USD) — заблоковане
платним тарифом Twelve Data — розблоковано через
`crypto/coingecko_adapter.py` (`kinesis-silver`, токен-проксі 1:1 до
фізичного срібла, metric_id `xagusd_close`; live-прогін користувача
проти БД ще не підтверджено, деталі й застереження — `docs/decisions.md`).

**Форекс/товари ПОЗА цим закритим watchlist-списком — закрито як
окрема задача (рішення користувача, 2026-09-26):** розширення переліку
валютних пар/товарів понад EUR/USD/USD/JPY/WTI/Brent/кава/метали
користувач вносить сам через файл вибраних активів — нові адаптери
на це не пишемо, це не техпріоритет проєкту.

**На майбутнє (фінальна стадія, зафіксовано 2026-09-26):** редагування
списку обраних активів (watchlist) через Telegram — не реалізовано,
відкладено до пізніших стадій проєкту.
