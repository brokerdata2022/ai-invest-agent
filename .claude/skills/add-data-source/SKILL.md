# Додавання нового джерела даних

Виконати по кроках, коли додається нове джерело (нове API, новий фід
новин, новий провайдер звітів):

1. Визначити категорію: macro / companies / news / reports — розмістити
   адаптер у відповідній підпапці data-ingestion/
2. Створити адаптер, що повертає дані у стандартизованому форматі
   (див. data-ingestion/CLAUDE.md — обов'язкові поля: source, metric_id,
   value, observed_at, fetched_at, revision)
3. Написати тест адаптера на фейкових/збережених прикладах відповіді
   API (не звертатись до реального API в тестах)
4. Додати потрібні env-змінні в .env.example (без значень)
5. Зареєструвати нове джерело в конфігу розкладу (monitoring/), якщо
   джерело має публічний календар релізів
6. Прогнати повний цикл руками: збір → перевірка запису в БД →
   переконатись, що observed_at/fetched_at коректні
7. Якщо джерело вимагало нетипового рішення (нестандартний формат,
   обхід rate-limit тощо) — записати одним реченням у
   docs/decisions.md
