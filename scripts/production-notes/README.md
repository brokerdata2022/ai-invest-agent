# Позначки для перенесених docs/

`scripts/build_production.sh` вставляє ці тексти в початок
відповідних файлів `production/docs/` — одразу після рядка `# Назва`.

- `<ім'я>.md` — позначка саме для `docs/<ім'я>.md`
- `_default.md` — для решти файлів зі списку `NOTED` у скрипті

**Чому окремі файли, а не рядок у скрипті.** Перша версія збірки
тримала текст позначки всередині `build_production.sh` і писала його
поверх файлу після кожного `rsync`. Наслідок: будь-яка продакшен-правка
в перенесеному `docs/` тихо знищувалась наступною перезбіркою — так
загинув вимір, що виправляв застарілу оцінку в `trading-list.md`.
Тепер позначки версіоновані тут, правляться в одному місці й
перезбірку переживають.
